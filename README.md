# مسرح الترددات المخفية — Hidden Frequency Theater

تطبيق ويب تفاعلي يعمل بالكامل داخل المتصفح (HTML5 + CSS3 + Vanilla JavaScript) بدون أي خادم خارجي أو مكتبات ثقيلة.

## الملفات (3 ملفات في نفس المجلد)

| الملف | الوصف |
|---|---|
| `index.html` | الهيكل + التنسيق (CSS) + الكود (JS) كاملاً ومنظّماً |
| `manifest.json` | بيانات تطبيق PWA، الأيقونات، وضع `standalone` |
| `sw.js` | Service Worker: التخزين المسبق والتشغيل دون إنترنت |

## التشغيل

> **مهم:** يجب تشغيل التطبيق عبر `http://` وليس بفتح الملف مباشرة (`file://`)، لأن Service Worker والميكروفون يحتاجان سياقاً آمناً (HTTPS أو localhost).

### الطريقة الأسرع — VS Code
1. ثبّت إضافة **Live Server**.
2. افتح مجلد `hidden-frequency-theater` في VS Code.
3. انقر بالزر الأيمن على `index.html` → **Open with Live Server**.

### الطريقة الثانية — سطر أوامر
```bash
cd hidden-frequency-theater
python3 -m http.server 8080
```
ثم افتح: `http://localhost:8080`

### النشر على استضافة
ارفع الملفات الثلاثة كما هي إلى أي استضافة ثابتة (GitHub Pages / Netlify / Vercel / أي خادم). لا حاجة لأي إعدادات بناء.

## طريقة الاستخدام

> **زر ؟ (دليل الاستخدام)** في الشريط العلوي يشرح كل زر وقسم على الجنب — من أسرع طريقة تعرف بيها التطبيق.

التدفق في القائمة الجانبية مرتّب كخطوات: **① اختَر الموسيقى → ② سجّل صوتك → ③ اضبط الموسيقى على صوتك تلقائياً → ④ (اختياري) استوديو الأناشيد → ⑤ اضغط تحميل**.

| الإجراء | التفاصيل |
|---|---|
| **① اختَر الموسيقى** | **تسع** مقطوعات جاهزة: 🌙 تأملي هادئ · ✨ بيت شعبي · 💥 تراب 808 · 🪕 عود شرقي · 🌊 لوفي هادئ · 🪘 عربي حديث · ⚡ تقني 4/4 · 🎷 جاز خفيف · 🎬 سينمائي — كل واحدة تضبط الإيقاع والمقام ونغمة الموجة والصدى تلقائياً |
| **② سجّل صوتك** | زر «تسجيل صوتك فقط» (أو العائم «صوتك فقط» على المسرح) — يُسجَّل صوتك وحده نظيفاً بينما تعزف فوق موسيقى الموقع |
| **③ اضبط الموسيقى على صوتك** | بعد التسجيل يقرأ التطبيق **إيقاعك ومقامك** من صوتك (تحليل مخطط الطاقة للسرعة + ارتباط ذاتي للطبقة الصوتية)، ثم يبني الموسيقى المختارة لتوافقهما تماماً — ويعرض النتيجة: «الإيقاع 117 BPM · المقام لا3» |
| **التحميل** | زر «تحميل مع الموسيقى» ينتج الملف النهائي (صوتك + موسيقى مضبوطة على إيقاعك ومقامك)، وزر «صوتك فقط» يحفظ الصوت الخام بلا موسيقى |
| **الكيبورد بالحروف (26 حرفاً)** | لوحة QWERTY كاملة أسفل المسرح: `Q W E R T Y U I O P` / `A S D F G H J K L` / `Z X C V B N M` — اكتب أي حرف ليُعزف، أو انقر المفتاح مباشرة. كل مفتاح يعرض **اسم نغمته وتردده** |
| **ترتيب النغمات** | الصف الوسطى هو السلّم الأساسي، والصف العلوي أوكتاف أعلى، والسفلي أوكتاف أخفض — وكل نغمة تنتمي للسلّم المختار. مع `Shift` ترتفع النغمة أوكتافاً |
| **نغمة طرفَي المسرح** | بطاقتان في أسفل يمين ويسار المسرح توضّحان أدنى وأعلى نغمة في مدى الرسم مع ترددهما |
| **العزف بالماوس/اللمس** | اسحب على المسرح — المحور الأفقي يحدّد النغمة، والسرعة تتحكم في شدّة الصوت |
| **ضوابط إضافية** | الموجة الصوتية، السلّم الموسيقي، النغمة الجذرية، مقدار الصدى، والتحكم الدقيق بالسرعة والمستوى |
| **ملف خفيف** | التسجيل بصيغة `Opus` داخل `WebM` — اختر «خفيف 48 kbps» لتحصل على ملف صغير جداً (≈6 KB لثانيتين)، أو ارفع الجودة إلى 96/128 kbps |
| **استوديو الأناشيد** | يحوّل تسجيلك إلى أنشودة: يستخرج خط النغمة، ويولّد كلمات عربية على مقام النغمة (قافية موحّدة، بلا تكرار)، ثم يغنّي الكلمات على نفس النغمة ويؤلّف موسيقى تتبع كل نغمة غُنّيت — ويمكنك تصدير الأنشودة كاملة بصوت غنائي + موسيقى |
| **تشغيل اللوب** | زر «تشغيل اللوب» في قسم «اللوب الخلفي» (وزر «تشغيل الموسيقى» في قسم اختيار الموسيقى) — كلاهما يشغّل نفس المشغّل، ويتحوّل نصّه إلى «إيقاف» أثناء التشغيل مع إضاءة المؤشّر الحيّ |
| **ملء الشاشة** | زر ⛶ في الشريط العلوي يفعّل ملء الشاشة (ويحاول قفل الاتجاه أفقياً) — والتطبيق عند تثبيته يفتح **ممتلئ الشاشة** بلا شريط متصفح ولا أزرار نظام |
| **الحلقة الحيّة** | سجّل مقطعاً (1/2/4/8 نبضة) فيتكرّر تلقائياً تحت عزفك — وعزف فوقه أو «سجّل أداءً فوق الحلقة» لدمج صوتك مع الحلقة في ملف واحد |
| **الموجة الصوتية والقصّ** | بعد التسجيل يظهر رسم الموجة داخل اللوحة — اسحب المقبضين لتحديد الجزء الذي تريد تصديره فقط |
| **الآلات** | ستّ آلات تلوّن عزفك: بيانو · عود · ناي · جيتار · أرغن · سينث — لكل واحدة غلافها ومرشّحها وارتجافها |
| **تعدد اللمس** | كل إصبع على المسرح يعزف نغمة مستقلة (polyphony) — مثالي على الموبايل |
| **الكاريوكي** | أثناء غناء الكلمات تُبرَز الكلمة الحالية تلقائياً على شريط الكلمات |
| **تصدير الأنشودة** | «صدّر الأنشودة» ينتج ملفاً صوتياً (غناء + موسيقى) و«تصدير الكلمات» ينتج ملف `.txt` |
| **أدوات سريعة** | «اضغط للإيقاع» (Tap Tempo) لضبط BPM بالضغط · «شارك المقطع» عبر نافذة المشاركة في الهاتف · «أبقِ الشاشة مضاءة» (Wake Lock) · زرا نقل الجذر نغمة أعلى/أخفض |
| **دليل الاستخدام (؟)** | زر **؟** في الشريط العلوي يفتح شرحاً كاملاً لكل زر وقسم في القائمة الجانبية — ويفتح تلقائياً في أول زيارة |
| **شبكة الإيقاع (16 خطوة)** | شبكة ٥ صفوف × ١٦ خطوة تتحكم في الباص والدف والدفّ والهاي واللحن — «خذ نمط المقطوعة» يملؤها بالنمط الحالي، ومؤشّر ذهبي يمشي على الخطوات أثناء التشغيل |
| **حفظ المشروع** | «احفظ المشروع» ينزّل ملف JSON فيه كل الإعدادات، و«افتح مشروعاً» يرجّعها، و«انسخ رابط الإعدادات» يعطيك رابطاً قصيراً يفتح في أي جهاز فيرجع كل شيء كما هو |
| **معايرة التأخير** | تقيس تأخير جهازك (بالنقر مع النقرات) وتزاح صوتك تلقائياً عند الدمج مع اللوب — عشان صوتك يبقى متزامناً مع الموسيقى |
| **طبقات التسجيل (Overdub)** | سجّل أكثر من طبقة (صوتك، عزف، غناء) — لكل طبقة مستوى مستقل، وكلها تندمج في الملف النهائي |
| **تثبيت التطبيق** | زر «تحميل التطبيق» في الأعلى — على iOS تظهر خطوات إضافة التطبيق إلى الشاشة الرئيسية |
| **المقامات العربية** | 6 مقامات عربية مضافة: راست · بايتي · صبا · نهوند · كرد · سيكاه — (بجانب الخماسي والحجاز والكبير والهارموني والدوري) و8 جذور نغمية. اختيار المقطوعة يختار مقامها المناسب تلقائياً |
| **السمات** | أربع سمات كاملة: داكن بنفسجي · بنفسجي · زمردي · فاتح (نهار) — وتُحفظ في المتصفح، مع خيار **«اجعل ألوان المسرح تتبع طاقة الموسيقى»** |
| **وضع سينمائي** | يخفي كل الواجهة ويترك المسرح وحده (اضغط «خروج» أو `Esc` للعودة) |
| **ميترونوم** | نقرات إيقاعية على نفس سرعة اللوب (BPM) للتدرّب قبل التسجيل |
| **عدّاد 3-2-1** | يبدأ التسجيل بعد عدّاد (يمكن تخطيه بالضغط أو بإلغاء الخيار) |
| **استيراد ملف صوتي** | اختر أي ملف (mp3/wav/m4a) من جهازك بدل الميكروفون — يُحلَّل إيقاعه ومقامه وتُضبط الموسيقى عليه |
| **معالج الصوت** | على تسجيلك: سرعة/تغيّر نغمة · صدى (Reverb) · تأخير (Delay) · مزاج الصوت (دافئ ↔ صافي) — مع زر «استمع للمعالجة» |
| **مكتبة التسجيلات** | كل تسجيل يُحفظ تلقائياً داخل المتصفح (IndexedDB) — تشغيل/تحميل/حذف، ويبقى بعد إغلاق الصفحة ويعمل دون إنترنت |
| **تصدير MP3** | مرمّز MP3 (lame.js) **مدمج داخل الملف** — اختر «MP3 192 kbps» من قائمة صيغة التصدير |
| **طيّ اللوحات** | زر «طيّ ▾» على لوحة النغمات يخفيها مؤقتاً لتوسيع المسرح، وزر القائمة في الأعلى يطوي القائمة الجانبية (ويمكن سحب حدّها لتغيير عرضها) |

## استوديو الأناشيد (من تسجيلك إلى أنشودة)

معلم مستقل داخل التطبيق يحوّل صوتك المسجّل إلى أنشودة كاملة — كله محلياً بدون خادم أو ذكاء اصطناعي خارجي:

1. **استخراج خط النغمة (Pitch Contour)** — يحلل التسجيل ويحوّله إلى سلسلة نغمات (piano-roll) مع إيقاع كل نغمة ومدّتها، ويعرضها كشريط مفاتيح مصغّر ملوّن.
2. **توليد الكلمات** — يبني كلمات عربية على مقام النغمة نفسها: 5 مواضيع (حنين / سفر / ليل / أمل / غَمد)، قافية موحّدة من مقطع الصوت الأخير لكل كلمة، مع ضمان عدم تكرار أي كلمة داخل السطر.
3. **الغناء** — مُصنِّع صوت بصيغة التشكيل (formants) يغنّي الكلمات المرفقة على نفس نغمتك الأصلية (لا لحن جديداً).
4. **الموسيقى** — تُؤلَّف كوردات تتبع كل نغمة غُنّيت، بنفس الإيقاع المستنتج.
5. **التصدير** — زر «صدّر الأنشودة» ينتج ملفاً نهائياً (صوت غنائي + مرافقة) بصيغة Opus/WebM، أو نسخة **نصية** (.txt) للكلمات فقط.

> يمكنك أيضاً تزويدي بلحن محدد (ملصوت أو وصف بالدرجة) أكتب لك كلمات تناسب قافيته ومقامه.

## ملاحظات

- **الشاشة الكاملة**: `manifest.json` يستخدم `display: "fullscreen"` مع `display_override: ["fullscreen","standalone","minimal-ui"]` — فعلى أندرويد يفتح التطبيق مثبَّتاً بملء الشاشة تماماً، وعلى iOS (الذي يتجاهل الـmanifest) يعتمد على `apple-mobile-web-app-capable` + `black-translucent` ليختفي شريط الحالة. الواجهة تستخدم `env(safe-area-inset-*)` فلا يغطي الـNotch أي زر.
- **جودة استخراج النغمة**: صار الخط أكثر ثباتاً — تصحيح أوكتاف تلقائي (يثبّت النغم على الأكثر تكراراً)، عتبة متينة تتعامل مع التسجيلات الهادئة، دمج المقاطع المتجاورة، وخطة بديلة تعامل المقطع كله نغمةً واحدة إن لم تتوفّر مقاطع. النتيجة: ملفات Quiet أو المستوردة تعمل الآن كما تعمل ملفات الميكروفون.
- **الصوت مؤكَّد**: تم تسجيل خرج المحرك من داخل المتصفح وتحليله طيفياً — الباص 23 dB، وذروة التردد عند النغمة المشغولة بالضبط (441 Hz لنغمة 440 Hz)، أي أن عزفك يخرج فعلاً من السماعات.
- **لا مكتبات خارجية**: مرمّز MP3 الوحيد (lame.js 1.2.1) مُدمج داخل `index.html` نفسه، فالمشروع يبقى 3 ملفات ويعمل دون إنترنت بالكامل.
- **المكتبة** تُخزَّن في IndexedDB داخل المتصفح — مسح بيانات المتصفح يمسحها.
- **الميكروفون** يتطلب إذن المتصفح (سيصلك طلب سماح عند بدء التسجيل).
- **التسجيل** يعمل داخل الصفحة دون أي رفع للسيرفر — الملف يُحفظ في جهازك مباشرة.
- بعد أول زيارة، يعمل التطبيق **دون إنترنت** بفضل خدمة Service Worker.
- التطبيق يعمل على الموبايل والكمبيوتر، والواجهة تتكيّف مع حجم الشاشة.
