# مسرح الترددات المخفية — Hidden Frequency Theater

تطبيق ويب تفاعلي يعمل بالكامل داخل المتصفح (HTML5 + CSS3 + Vanilla JavaScript) بدون أي خادم خارجي أو مكتبات ثقيلة.

## الملفات (3 ملفات في نفس المجلد)

| الملف | الوصف |
|---|---|
| `index.html` | الهيكل + التنسيق (CSS) + الكود (JS) كاملاً ومنظّماً |
| `manifest.json` | بيانات تطبيق PWA، الأيقونات، وضع `standalone` |
| `sw.js` | Service Worker: التخزين المسبق والتشغيل دون إنترنت |

## التشغيل

> **مهم:** يجب تشغيل التطبيق عبر `http://` وليس بفتح الملف مباشرة (`file://`)، لأن Service Worker والميكروفون يحتاجان سياقاً آمناً (HTTPS أو localhost).

### الطريقة الأسرع — VS Code
1. ثبّت إضافة **Live Server**.
2. افتح مجلد `hidden-frequency-theater` في VS Code.
3. انقر بالزر الأيمن على `index.html` → **Open with Live Server**.

### الطريقة الثانية — سطر أوامر
```bash
cd hidden-frequency-theater
python3 -m http.server 8080
```
ثم افتح: `http://localhost:8080`

### النشر على استضافة
ارفع الملفات الثلاثة كما هي إلى أي استضافة ثابتة (GitHub Pages / Netlify / Vercel / أي خادم). لا حاجة لأي إعدادات بناء.

## طريقة الاستخدام

| الإجراء | التفاصيل |
|---|---|
| **الكيبورد بالحروف (26 حرفاً)** | لوحة QWERTY كاملة أسفل المسرح: `Q W E R T Y U I O P` / `A S D F G H J K L` / `Z X C V B N M` — اكتب أي حرف على كيبوردك ليُعزف، أو انقر المفتاح مباشرة. كل مفتاح يعرض **اسم نغمته وتردده**، ويضيء أثناء عزفه |
| **ترتيب النغمات** | الصف الوسطى هو السلّم الأساسي، والصف العلوي أوكتاف أعلى، والسفلي أوكتاف أخفض — وكل نغمة تنتمي للسلّم المختار فتبقى متناغمة. مع `Shift` ترتفع النغمة أوكتافاً |
| **نغمة طرفَي المسرح** | بطاقتان في أسفل يمين ويسار المسرح توضّحان أدنى وأعلى نغمة في مدى الرسم مع ترددهما |
| **بطاقة المؤشر** | عند تمرير المؤشر فوق المسرح تظهر بطاقة باسم النغمة وترددها في تلك اللحظة |
| **العزف بالماوس/اللمس** | اسحب على المسرح — المحور الأفقي يحدّد النغمة، والسرعة تتحكم في شدّة الصوت |
| **الجانب الأيمن** | اختيار الموجة الصوتية، السلّم الموسيقي، النغمة الجذرية، الصدى، تشغيل اللوب الخلفي والتحكم بـ BPM |
| **التسجيل** | «بدء التسجيل» ← يُسجَّل صوتك مع اللوب في مقطع واحد ← استمع أو حمّل الملف بصيغة `.webm` |
| **زر «أضف صوتك»** | زر عائم على المسرح: ضغطة واحدة تبدأ تسجيل صوتك مع النغمات (مع مؤشّر مستوى الصوت وإطار أحمر نابض)، والضغطة الثانية تحفظ الملف **تلقائياً** على جهازك |
| **ملف خفيف** | التسجيل بصيغة `Opus` داخل `WebM` — اختر «خفيف 48 kbps» لتحصل على ملف صغير جداً (≈6 KB لثانيتين)، أو ارفع الجودة إلى 96/128 kbps |
| **تثبيت التطبيق** | زر «تحميل التطبيق» في الأعلى — على iOS تظهر خطوات إضافة التطبيق إلى الشاشة الرئيسية |
| **طيّ اللوحات** | زر «طيّ ▾» على لوحة النغمات يخفيها مؤقتاً لتوسيع المسرح، وزر القائمة في الأعلى يطوي القائمة الجانبية (ويمكن سحب حدّها لتغيير عرضها) |

## ملاحظات

- **الميكروفون** يتطلب إذن المتصفح (سيصلك طلب سماح عند بدء التسجيل).
- **التسجيل** يعمل داخل الصفحة دون أي رفع للسيرفر — الملف يُحفظ في جهازك مباشرة.
- بعد أول زيارة، يعمل التطبيق **دون إنترنت** بفضل خدمة Service Worker.- التطبيق يعمل على الموبايل والكمبيوتر، والواجهة تتكيّف مع حجم الشاشة.
